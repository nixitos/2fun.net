# Jurisdiction & Liability

**2fun.net** is a minimalistic anonymous forum engine.  
It provides a technical ability to post and read text-based content.

## No Moderation
- The software does not include any automated or manual content filtering.
- There are no moderators, administrators, or any personnel reviewing posts.
- Every user is fully responsible for what they publish.

## No User Analytics
- The platform does not collect:
  - IP addresses (not logged, not stored)
  - Browser fingerprints
  - Session data
  - Any personal identifiable information
- No cookies are used for tracking.
- No third-party analytics services are integrated.

## Technical Limitations
- Only text is supported — no images, no file uploads.
- Posts are stored in a database with auto-cleanup (old threads are removed automatically).
- Rate limits and cooldowns exist solely to prevent technical abuse (DDoS, spam), not to control content.

## Liability Disclaimer
**2fun.net** is a tool, similar to a public notebook or a messaging board.  
The creator and host of this software:
- Do not read, review, or pre-approve any content.
- Cannot be held responsible for how users choose to use the platform.
- Do not have any technical means to moderate content without fundamentally changing the nature of the project.

Any legal requests (DMCA, content removal, user identification) cannot be fulfilled due to the absence of:
- User accounts
- Contact information of posters
- IP logs
- Any moderation interface

## Jurisdiction
The software is hosted on distributed free-tier cloud services.  
No single legal entity controls the entire infrastructure.  
The creator does not reside in or operate from any specific jurisdiction that claims authority over this project.

## Final Note
If you disagree with anything posted on 2fun.net — do not use it.  
The platform does not seek to violate any laws. It simply does not have the technical ability to comply with content regulation.

*— 2fun.net is a public tool. What you do with it is your own business.*
